# 冒险岛怀旧服国服 · 自动练级工具

> **这个文件是给「只想用、不想碰代码」的人看的。**
> 想看源码、自己改、自己打包 —— 看 [README.md](README.md)。

一个帮你自动打怪的挂机工具。它**不读游戏内存、不改游戏文件**，做法跟人一样：看游戏画面 → 认出怪和自己在哪 → 按键盘。

> **这个项目最初是应朋友之托写的** —— 结果好不容易做完了，他**怕封号，一直没敢用**。我自己也弃坑得比较早，角色只练到 **25 级**就没再玩了。
>
> 开发期间一直拿自己的账号边测边改，**前后测了大约一个星期，账号到现在还是正常的** —— 但这只是我一个人的样本，**仅供参考**，不代表你的号也一定安全。
>
> 另外：**我本机的依赖环境是完整装好的**，所以没法复现「一台干净电脑上第一次安装」会遇到什么。**初次使用很可能碰到各种 bug**，我会持续修，也欢迎提 issue，请多担待。
>
> **请自行评估风险，使用后果自负**（见文末免责声明）。

> ⚠️ **开始之前先知道一件事**：这个工具要**额外装一个键盘驱动**才能工作（不装的话，程序能开、能点，但角色一动不动）。
> 它开源可审计、装法也简单，**就在下面「一、先下载」里** —— 我们先把它是什么、安不安全讲清楚，再带你装。

## 一、先下载

**去 [Releases 页面](../../releases/latest) 下载。** 那里每个版本都有两个文件，按自己情况挑一个：

| 我是什么情况 | 下哪个文件 | 多大 |
|---|---|---|
| **第一次用** | 名字是 `MapleStoryAutoLevelUp-CN-....zip`（**不带 `patch-to-`** 的那个） | 100 MB 出头 |
| **已经装过旧版** | 名字是 `patch-to-....zip`（带 `patch-to-` 的那个） | 几 MB |

> 💡 **怎么认**：看文件名开头就行 —— **`patch-to-` 开头的是补丁**（给已经装过的人用），
> **其它的才是完整包**（第一次用选这个）。名字中间那串版本号不用管。

### 该下哪个版本？beta 还是稳定版？

发行页里会同时有两类，**看文件名里有没有 `beta` 字样**：

| 文件名里有… | 是什么 | 建议 |
|---|---|---|
| 有 `beta` | **测试版**：功能最新，但可能不稳 | 想尝新、愿意帮忙试错就用它 |
| 没有 `beta` | **稳定版**：经过更多实际使用 | **想稳妥就用它** |

> 具体有哪些版本、哪个是最新，**一律以发行页上写的为准**，这里不重复列 —— 免得和发行页对不上。

### ⚠️ 第一次装：还要单独装一个「按键驱动」

**这一步不能跳过。** 程序用内核级驱动给游戏发按键 —— 驱动是**独立的东西**，装完程序还要单独装它一次。

不装会怎样：程序能打开、也能点开始，但**角色一动不动**。

#### 关于这个按键驱动：它是什么，安不安全

**一句话**：它叫 **Interception**，是一个**开源、免费、公开可审计**的键盘鼠标驱动，很多自动化和按键需求都在用它，不是外挂作者写的黑箱。它不联网、不读游戏内存、不采集数据，你在设备管理器里能直接看到它。

**为什么非装不可？** 上游台服版走的是另一条路：用 **KMbox**，一种要**单独花钱买**的硬件外设（插在电脑上的盒子，由它在硬件层面冒充键盘）。我试下来发现，**用 Interception 这个软件驱动方案可以绕开 KMbox** —— 不用额外花一分钱，装个驱动就行。

**为什么不装就不动？** Windows 发按键有两条路：普通程序按键是**"伪造 + 声明"**，游戏能识破并忽略；Interception 走的是**驱动层**，按键从驱动进入系统，路径和真键盘一样。

**它安全吗？逐条说：**

- **开源可审计**：源码、安装包全部公开放 [在 GitHub](https://github.com/oblitum/Interception)（`oblitum/Interception`），全世界都能看它到底干了什么，**没有闭源部分，也不是破解版**；
- **不干坏事**：不联网、不上传数据、不采集账号信息。它只做"把按键送进系统"这一件事；
- **能卸、能回滚**：不想要了，用 `install-interception.exe /uninstall` 卸掉，重启即恢复；
- **它管不着游戏**：驱动只管发按键，**打哪只怪、走哪条路线是程序在判断**。驱动本身不知道你开的是什么游戏 —— 装在记事本上也是同样的用法。

**和外挂的本质区别**：内存挂、注入挂要**钻进游戏进程改数据**，那种才危险。Interception **从头到尾没碰游戏进程一个字节**，它只是让系统按了几下键盘。

> ⚠️ **必须说清楚的一点**：驱动本身安全，**不等于用它玩游戏就不违规**。官方禁止的是"自动化操作"这件事，不在于你用什么方式实现 —— **是驱动还是 KMbox，对封号判定没有豁免作用**。这一点请务必知悉。

#### 怎么装（只做一次）

1. 打开 https://github.com/oblitum/Interception/releases/latest ，下载 `Interception.zip` 并解压；
2. 进解压出来的文件夹，在地址栏输入 `cmd` 回车（用**管理员身份**打开命令提示符）；
3. 执行：
   ```
   install-interception.exe /install
   ```
4. **重启电脑**（不重启不生效），再打开本程序。

装对了的话，程序日志里不会再出现 `Interception 初始化失败`。

> ✅ **Win11 上看到报错别慌**：安装时如果最后卡在 `Could not write to \system32\drivers`，**这其实是装成功了**，不用重试也不用管它。这个报错是安装器写完驱动后清理临时文件失败留下的（[上游 issue #215](https://github.com/oblitum/Interception/issues/215)），驱动本体已经就位——**直接重启电脑，然后开本程序验证即可**。判断装没装成的唯一标准是：程序日志里不再出现 `Interception 初始化失败`，以这个为准，不要以安装时的报错为准。

> 💡 如果驱动没装，你在点「开始」时程序会**直接弹窗告诉你怎么装**，不用自己找。
>
> ⚠️ 极少数机器装完这个驱动会出现键鼠异常。万一遇到：开机时进**安全模式**，删掉 `C:\Windows\System32\drivers\` 下的 `keyboard.sys` 和 `mouse.sys` 即可恢复。装之前先记一下这条。

### 第一次装：完整包

1. 下载后**解压整个文件夹**（右键 → 解压到当前位置）；
2. 进文件夹，**右键 `冒险岛自动练级.exe` → 以管理员身份运行**。

> ⚠️ **不要只把 exe 拿出来用**。它需要旁边的文件夹才能跑，必须整个文件夹一起解压。
>
> ⚠️ **建议一开始就用管理员身份运行**。游戏客户端通常是管理员权限启动的，
> 普通权限的程序**收不到游戏里按的键**（Windows 的机制），表现就是「录路线时角色不动」。
> 想省事可以右键 exe → 属性 → 兼容性 → 勾上「以管理员身份运行此程序」。

### 升级：老用户打补丁

1. 先**关掉**冒险岛自动练级程序；
2. 把补丁 zip 解压到**任意位置**（解压本身不会动你的程序）；
3. 双击里面的 `应用补丁.bat`，按提示回车。

脚本会自己找到程序目录（找不到会问你路径），先把要替换的文件备份到 `_backup_补丁前` 文件夹，再覆盖。

**你的配置、地图路线、怪物模板都不会被碰。** 万一出问题，把备份文件夹里的东西复制回程序目录就还原了。

## 二、第一次用要做准备

工具是「看画面」干活的，所以它得先认识**你的角色**和**你要打的图**。装完是空的，要自己做一遍。

**开始前先确认两件事：**

- 游戏要开**窗口模式**（不能全屏）—— 工具靠 Windows 自带的截取能力"看"画面，**它抓不到独占全屏的游戏**；
- 游戏左上角的**小地图要打开**（工具靠它判断你在哪）。

> 💡 顺带说明：**「看画面」这件事不需要装任何东西**，用的全是 Windows 自带的能力。
> 整个工具只有「发按键」要装驱动（就是第 1 步那个）。

**然后按这 4 步做：**

### 第 1 步：让工具认识你的角色（F2）

在主界面按 `F2`：

1. 弹出的框里填**你角色的名字**（要和游戏里显示的完全一样），点确定；
2. 然后游戏画面上会出现框选提示 —— 用鼠标**框住角色的名字**那一行，再**点一下角色中心**。

> 只有换角色才需要重做。不标的话，工具找不到你在哪，走位会乱。

### 第 2 步：教它走一条路线（F4）

在主界面按 `F4`，给这张图起个名字（中文就行，比如「蘑菇村」）。

会弹出一个置顶的小面板，**全程用鼠标点按钮**：

1. 让角色**站到路线的起点**，点【开始录（我站好了）】；
2. 一路走到平台另一头，点【在这折返，存下这段】；
3. 再走回起点附近，点【这是终点，保存这段】；
4. 点【主线录完了，下一步】。

> ⚠️ **去程和回程一定要分成两段**。挤在一段里的话，同一个位置既有向左又有向右的记录，角色会一路冲出平台。
>
> **这一步也会把地图创建出来** —— 后面第 3 步要在列表里选它。

#### 顺便说下「回正线」——它管的是「掉下去之后怎么爬回来」

**主线**是平时来回巡逻的那条路。但打怪时角色可能被怪撞飞、或者自己走偏，**掉到平台下面去**。这时光有主线没用 —— 它在上面，角色够不着。

**回正线**就是专门录"从坑里爬回主线"的那条路。掉下去之后，工具会沿着它把角色带回来。

**要不要录？强烈建议录。** 不录的后果是：角色一旦掉下去，就**只能站在坑里干等**，自己回不来（不会报错，你可能要好一会儿才发现它在发呆）。

**怎么录**（就在同一个 F4 面板里，主线录完之后）：

1. 让角色**真的掉下去一次**，站在落点上；
2. 点【我在落地点】—— 记下落点；
3. 一路走回主线上；
4. 点【已回到主线】—— 保存。

> 💡 一张图可能有**好几个地方会掉下去**（左边一个坑、右边一个坑）。每个落点都要单独录一条 —— 录完一条后可以再点【我在落地点】补下一条，它们会叠在一起。
>
> 💡 **不想开游戏跑一遍也行**：主界面有【🖊 手绘回正线（推荐）】，直接在图上画，画完当场就能看到能不能用。
>
> ⚠️ 坑里如果没有录过回正线，工具会打日志说「附近找不到回正线像素……暂时放弃回正、先打怪」，并告诉你去补录。看到这条日志不用慌，去补一条就行。

### 第 3 步：选中这张图

关掉界面，重新打开 —— 刚录的图会出现在下方的地图列表里，**点它选中**。

### 第 4 步：告诉它打哪种怪（F3）

按 `F3`，用鼠标**框住一只怪**，工具会自动抠图存档。

- 一只怪**截 2 个姿态就够**（比如站着 / 攻击时），挑差别大的两种；
- 游戏是横版，怪只有左右两个朝向，工具会**自动镜像**，所以不用自己截反面；
- 感觉漏怪 / 打空 → 多截几个姿态；
- 感觉变卡了 → 用「模板查重」清理重复的。

## 三、开始挂机

准备做完，按 `Start` 或 `F1` 就开始自动打怪了。

**界面上的快捷键：**

| 键 | 干什么 |
|---|---|
| `F1` | 开始 / 暂停 |
| `F2` | 标定角色名字（换角色才用） |
| `F3` | 截怪物模板（换图才用） |
| `F4` | 录挂机路线 |

关掉界面直接点窗口右上角的 × 即可。

**挂机时注意：**

- 游戏窗口要**一直开着**，别最小化（挡住了没关系，最小化不行）；
- 界面**「工具箱」页签里有完整的图文教程**，忘了怎么操作可以随时翻。

### 🧪 自动喝药（新功能）

**一句话**：工具会一直看着你的血条和蓝条，血少了 / 蓝少了就自动帮你按药水键。

界面上有一块「🧪 自动喝药」，里面能看到：

- 现在血多少、蓝多少（挂机时实时更新）；
- 低于多少会自动喝、喝的是哪个键；
- 一个开关 —— 想自己控药（比如打 BOSS）就把它关掉，挂机照常跑，只是不自动喝药。

**要你自己设的只有一件事：药水键。**

出厂默认是 `pageup`（大补）、`home`（普通红药）、`end`（蓝药）。
**这三个键要和你在游戏里给药品绑的键一致**，否则按了也不生效。
改法：界面「高级设置」页签 → 找到 `potion` → 改 `key` 那几项
（填 `null` 表示这一档不自动喝）。

> 想先确认它到底看不看得见你的血条：点面板上的「🔍 试一下（读一次血蓝）」，
> 它会当场读一次并告诉你结果，不用先开挂机。

**⚠️ 自动喝药对环境有要求（三条都要满足）：**

| 要求 | 怎么设 |
|---|---|
| 游戏分辨率 | 游戏里设成 **1366x768**，用**窗口化**运行 |
| Windows 缩放 | 「设置 → 系统 → 显示 → 缩放」设成 **100%** |
| 双屏用户 | 两个屏幕缩放不一样时，把游戏窗口放在**主屏幕**上 |

> 这个游戏的最大化按钮是**灰的、点不了**，所以不用管它；**全屏不行** ——
> 全屏会直接使用你显示器的分辨率，就不是 1366x768 了。

**为什么这么严**：血条的位置是一个像素一个像素量出来的，窗口大小或缩放一变，
量的位置就不对，读出来的血量就是错的。与其读错，不如把环境卡在一套量准了的值上。

这三条没同时满足时，工具会**明确告诉你哪里不对、该怎么改**，不会悄悄读错。
不满足时挂机打怪照常，只是不自动喝药。

> 如果提示「游戏画面大小不对」，把上面三条逐条对一遍 —— 尤其注意**缩放 100%**，
> 多屏用户对不上多半是它造成的。

## 四、遇到问题

### 点了开始，角色一动不动 / F2、F3、F4 没反应

按顺序查这两条，**大概率是其中之一**：

**① 按键驱动没装**（最常见，新装用户几乎都会遇到）

程序能开、能点，但按键送不出去。看日志（`log` 文件夹里最新的 `.log`），如果看到：

```
Interception 初始化失败: Interception driver was not found or is not installed
```

→ 就是它。装法见上面「**第一次装：还要单独装一个按键驱动**」那一节。

**② 没用管理员身份运行**

这个工具用内核级驱动发按键，必须管理员权限，否则 Windows 会静默拦掉。

→ 关掉程序，右键 `冒险岛自动练级.exe` →「以管理员身份运行」。

> 想一劳永逸：右键 exe → 属性 → 兼容性 → 勾上「以管理员身份运行此程序」。

### 按 F4 后卡住 / 提示「抓不到游戏画面」

工具要按固定尺寸去看游戏画面。**窗口大小对不上，就一帧都拿不到。**

> 为什么会有大小对不上这回事：程序里存的「窗口应该多大」是**开发机上量出来的**。
> 而你的显示器分辨率、**Windows 缩放比例**（100% / 125% / 150%）跟开发机不一样时，
> 同一个游戏窗口量出来就不同 —— 这跟你的操作没关系。

按 `F4` 时如果尺寸不对，会直接弹窗告诉你差多少，并给一个按钮：

> **「一键按当前窗口大小改配置（推荐）」**

点它就自动改好了，然后继续录制流程。不用手动算尺寸。

> 如果游戏窗口之后又改了大小（比如换显示器、改了缩放），重新点一次这个按钮即可。
>
> 老版本只会笼统提示「请检查窗口是否被挡住或最小化」，容易让人以为是双屏或焦点问题 —— 其实和那些无关。

### 挂机时提示「抓不到游戏画面」/ 画面不动

按下面的顺序查，**前三条最常见**，一般到第三条就解决了：

**① 游戏窗口被最小化了**

这是最容易忽略的一条。**窗口被别的窗口挡住没关系，但最小化不行** ——
游戏一最小化，Windows 就不画它了，工具一帧画面都拿不到（而且**不会报错**，
看起来像"卡住了"）。

→ 点任务栏上的游戏窗口把它**还原**（别停在最小化状态），再按 `F1` 继续。

**② 游戏不是窗口模式**

Windows 的这个截取方式**抓不到独占全屏**的游戏。

→ 在游戏设置里改成**窗口化**运行。注意"全屏"和"无边框全屏"都不行。

**③ 窗口大小和工具记的不一致**

→ 按 `F4` 或重新点一次「一键按当前窗口大小改配置」。

**上面三条都对，还是抓不到画面？**那很可能是**运行方式**的问题。

这个工具需要**显卡直接出力**来读画面。下面两种情况显卡能力会被"截断"，工具就读不到画面：

| 情况 | 怎么办 |
|---|---|
| 你是**通过远程桌面**连到这台电脑操作的（向日葵、ToDesk、Windows 自带的远程桌面等） | 请在**这台电脑本机**上直接操作（就是坐在它前面用），别隔着远程连 |
| 工具装在**虚拟机**里（VMware / VirtualBox / Hyper-V 等） | **本工具不支持在虚拟机里运行**，请换一台普通电脑 |

> **不确定自己是不是虚拟机？** 打开**任务管理器** → 左边选「性能」 → 看有没有「虚拟机」字样。
> 或者回想一下：装系统时是不是"在别人的 Windows 里又装了一个 Windows" —— 是的话就是虚拟机。
>
> 注意：很多电脑支持的「虚拟化」功能（比如 WSL、某些安全功能）**不算**虚拟机，不影响使用。

> 顺带说一句：上面「远程桌面」那条是**推测** —— 按原理它会影响抓屏，但我们**没有实测过**。
> 如果你正好是远程桌面环境、又确认前三条都没问题，欢迎来 [开 issue](../../issues) 告诉我们，
> 帮我们确认到底是不是这个原因。

### 界面打不开 / 一闪就没了

程序几乎没有「闪一下就消失」的情况（它是图形界面，正常会停在窗口上）。真遇到的话，按顺序试：

1. **确认是解压后再双击的**。直接在压缩包里双击 exe、或者只把 exe 单独拖出来，都会打不开 —— 它需要旁边的文件夹；
2. 检查杀毒软件是否拦截了（这类工具常被误报），把它加进信任列表；
3. 打开程序文件夹里的 **`log`** 目录，看有没有当天的 `.log` 文件，把里面的内容发给作者。

> 如果你是**从源码运行**（自己装了 Python），可以用 `诊断启动.bat` 带黑窗口启动看报错 —— 免安装包里没有这个文件。

### 自动喝药不工作 / 一直在喝

**先点面板上的「🔍 试一下（读一次血蓝）」**，它会直接告诉你读到了多少。

- **读不到血条** → 多半是环境不对（分辨率 / 窗口化 / 缩放 100%，见上面那一节）。
- **血是满的，但一直在喝** → 说明读出来的数值偏高或偏低。
  先确认游戏画面是 1366x768 且系统缩放 100%；还不行就把这件事报上来
  （带上 `log` 文件夹里最新的 `.log`）。
- **血真的低了，但一次都没喝** → 检查**药水键有没有设对**：
  出厂默认是 `pageup` / `home` / `end`，必须和你在游戏里绑的一致。
- **我切到别的窗口了，它还会按键吗** → 不会。
  工具只在**游戏窗口在最前面**时才按药水键，避免按键落到浏览器或编辑器上。

### 角色掉到平台下面，站在坑里不动

**没录过这个坑的回正线** —— 工具不知道怎么爬回来，只能原地等。

看日志里有没有这句：

```
附近找不到回正线像素（搜索 10px / 救援 40px 都够不着）—— 这条回正线覆盖不到这里
```

→ 去补一条：按 `F4` 选【补录回正线】（旧路线不动）→ 让角色掉到那个落点上 →【我在落地点】→ 走回主线 →【已回到主线】。

> 也可以不开游戏，用主界面的【🖊 手绘回正线（推荐）】直接画。
>
> 详见上面「**顺便说下「回正线」**」那一节。

### 角色不走 / 走一下就停

按顺序检查：

1. 游戏窗口是不是**前台**（被别的窗口盖住、或者最小化了都不行）；
2. 是不是没勾对地图 —— 主界面下方列表里**选中**要挂的那张图；
3. 怪物模板是不是没截（第 4 步）。

### 还是不行

在程序的 `log` 文件夹里找最新的那个 `.log` 文件，连同你的操作步骤一起发给作者，这样定位最快。
